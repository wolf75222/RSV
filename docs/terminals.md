# Terminals

RSV is meant to be used over SSH, from any terminal.

- **Colors.** Over SSH a program can't ask the terminal whether it has 24-bit colors: `COLORTERM` isn't forwarded, and ROMEO accepts no environment variable from the client. FTXUI then picks 256 colors from `TERM=xterm-256color`, and does it again when its loop starts. RSV uses 24-bit colors anyway (nearly every terminal used to reach ROMEO has them) and puts its choice back before each frame. Exceptions: `NO_COLOR`, the Linux console and GNU screen (outside tmux). If the colors look wrong (Apple's Terminal before macOS 26 has only 256), set `RSV_COLOR=256` or use `--color 256`.
- **Alignment.** Columns are measured in display columns and names are cut by width, not by bytes: accents, CJK (2 columns) and emoji keep the columns aligned. Invisible characters (zero-width spaces, direction marks, variation selectors) are removed from names and logs, since terminals and FTXUI don't agree on their width. Escape sequences in a log (colors, progress bars with `\r`) are removed too.
- **Small terminals.** Below 90 columns the list goes above the details. Columns that don't fit are dropped (history, partitions), node cells wrap to the width, and the details scroll (`J` `K`). Below 40×10 RSV says the terminal is too small instead of drawing a broken screen.
- **Mouse.** Clicks and the wheel work (select a job, scroll). Mouse moves aren't asked for: each one would redraw the whole screen over SSH. While the mouse is on, select text with `Shift` (or `Option` on macOS) held, or start RSV with `--no-mouse`.
- **Copy.** `y` copies through the terminal (OSC 52), so it reaches the clipboard of the computer in front of you, not the login node's (RSV 1 ran `xclip` there, which had no display to copy to). kitty, WezTerm, Ghostty, Alacritty, Windows Terminal and foot accept it; iTerm2 once "Applications in terminal may access clipboard" is on (Settings › General › Selection); tmux with `set -g set-clipboard on`. Elsewhere the id is still shown in the bottom line.
- **Dropped connection.** When SSH drops, RSV quits instead of staying on the login node, even if the hangup signal doesn't reach it.
